# Structured

A personal visual day planner and work tracker, inspired by the Structured app. It adds goal tracking and a Claude (MCP) connector, so Claude can plan the day.

- **Web app**: React, TypeScript, Vite, Tailwind
- **Android app**: Capacitor
- **Backend**: Supabase (Postgres and Realtime)
- **Claude integration**: remote MCP server

This is a work in progress, built phase by phase. See [`PLAN.md`](PLAN.md) for the full plan and [`HANDOFF.md`](HANDOFF.md) for the current status.
